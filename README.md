# Гостиона Код 4 Лава — сајт

Статички сајт (Astro + TypeScript + GSAP) за Гостиону Код 4 Лава, Трг Бранка Радичевића 3, Сремски Карловци.
Три језика: `/` ћирилица · `/lat/` латиница (аутоматски из ћирилице) · `/en/` енглески.

## Како се мења садржај (без дирања кода)

- **Јеловник и цене** — `src/data/menu.json`. Називи се пишу ћирилицом (`name.sr`), латиница се прави сама. Енглески у `name.en`. `price: null` = цена се не приказује. Латинички називи који не смеју да се пресловљавају пишу се као `{=Wine country burger=}`.
- **Радно време, телефон, оцена** — `src/data/info.json` (`hours.week`: 1 = понедељак … 7 = недеља).
- **Вина и бермет** — `src/data/wines.json`.
- **Утисци гостију** — `src/data/reviews.json` (само праве рецензије, са именом и извором).
- **Текстови сајта** — `src/i18n/sr.json` (ћирилица) и `src/i18n/en.json`.
- **Галерија („ролна“)** — фотографије јела у `src/assets/gallery/` (Astro их претвара у AVIF/WebP), па их наведите у `src/data/gallery.json`: `{ "images": [ { "file": "gulas.jpg", "alt": { "sr": "Јунећи гулаш", "en": "Beef goulash" } } ] }`. Док је листа празна, ролна се не приказује. (Мало одступање од брифа: `src/assets/` уместо `public/img/gallery/`, да би Astro могао да оптимизује слике.)
- **Фотографија улаза** — `public/img/vrata.jpg` (појављује се сама у „Како да нас нађете“).
- **Сезонски банер** — `info.json` → `seasonalBanner.active`: `"berba"`, `"bozic"`, `"uskrs"` или `null`.
- **Поклон-ваучер** — прави се у прегледачу (штампа или PNG); ништа се не плаћа преко сајта.
- **Доба дана** — сајт се сам мења ујутру (06–11), подне (11–17) и увече (17–06). У подножју су скривени тастери A / ☀ / ◐ / ☾ за демонстрацију.
- **Пост** — трака „Посни дани“ се појављује сама током Божићног, Великог, Петровског и Госпојинског поста (`src/lib/fasting.ts`, са тестовима), а средом и петком као блага напомена.
- **Јело дана (креда табла)** — два начина:
  1. `src/data/daily.json` → `items` (назив ћирилицом, енглески, цена) и `weekly` (стални дани: уторак шкембићи, четвртак Рожин паприкаш, недеља Војвођански ручак).
  2. **Са телефона, без програмера:** направите Google табелу са колонама `sr`, `en`, `price` (први ред су наслови, нпр. `Добар јунећи гулаш | A good beef goulash | 1300`). У Google Sheets: *Датотека → Дели → Објави на вебу → изаберите лист → формат „CSV“ → Објави*, копирајте линк и упишите га у `info.json` → `dailySheetCsv`. Сајт сваки пут чита табелу (чека највише 3 секунде); ако не успе, приказује `daily.json`. Власник после само мења табелу из Google Sheets апликације на телефону.
- **Јеловник на сајту** — све из `menu.json`: `featured` → „Специјалитети куће“, `preorder` → „Испод сача / Јела по поруџбини“ и формулар за наруџбину, `preorderHours` → најранији датум, `origin` → прекидач Беч | Цариград, `tags` → филтери (`fasting` = Посно), `pairing` → „Уз ово: вино“ и точак спајања, `hidden: true` → не приказује се. У режиму развоја (`npm run dev`) ставке са `verify: true` имају црвену тачку.
- **QR јеловник** — `/meni/`, `/lat/meni/`, `/en/meni/` (брза страна, ~6 KB JavaScript-а: претрага, филтери, отворено/затворено).
- **Интро (чесма → мала врата)** — види одељак „Интро“ испод.

## Интро „Попиј воду са чесме“

Приказује се **само при првој посети** почетне стране (памти се у прегледачу). Ток: чесма → цитат „Ко се напије воде са чесме, вратиће се у Карловце.“ → „Попиј гутљај“ (држите или додирните, златни прстен се попуни за ~1 s) → прелаз на мала врата која се отворе у топлој светлости → сајт. Од додира до сајта ~4,5 s. Дугме „Прескочи · Skip“ је увек видљиво, Esc прескаче. Са искљученим анимацијама: једна слика и дугме „Уђи“. Додајте `?nointro` на адресу да га заобиђете.

**Снимци → интро (исти поступак за демо и за власников снимак):**
1. Ставите фајлове у `raw/intro/`. Име одређује сцену: у имену `vrata`, `door`, `ulaz` или `entrance` → сцена 2 (мала врата); све остало → сцена 1 (чесма). Пример: `cesma.mp4`, `cesma-01.jpg`, `cesma-02.jpg`, `vrata.jpg`.
2. Покрените `npm run intro` (демо, Google мапе) или `SOURCE=own npm run intro` (сопствени снимак).
3. `npm run build`.

Скрипта (`scripts/process-intro.sh`, ffmpeg) сама: бира најмирнијих ~3,5 s, стабилизује (vidstab), сече 16:9 и 9:16, изоштрава и уклања шум, боји у тонове сајта (топло, црвено ка мермеру, зелено пригушено, зрно, вињета), извози H.264 MP4 + VP9 WebM без звука (≤ 2,5 MB, проверено) и постере; фотографије увећава, исто боји и извози AVIF/WebP/JPG за рачунар и телефон. Резултат: `public/intro/` + `src/data/intro.json`; сајт се сам пребацује: **видео → фотографије (Ken Burns, смењивање) → илустрована чесма** (сада, док нема материјала). Исти снимак чесме постаје и затамњена позадина на врху почетне стране (паузира се ван екрана). Сваки демо фајл се уписује у `src/data/assets-demo.json` са `replaceBeforeLaunch: true`.

## QR кодови за столове

```bash
PUBLIC_SITE_URL=https://www.pravi-domen.rs npm run qr
```
Прави фасциклу `qr/`:
- `meni-sr.svg/.png`, `meni-lat.svg/.png`, `meni-en.svg/.png` — QR код са полу-лавом у средини (ниво корекције грешке H, па лав не смета скенирању; проверено декодирањем).
- `stoni-karton-a6.html` — стони картон A6 у барокном оквиру. Отворите у Chrome-у → Штампај → „Сачувај као PDF“, величина A6, размера 100 %.

⚠ QR кодови се праве тек кад је познат прави домен — без `PUBLIC_SITE_URL` воде на `example.com` (само за демо).

## Демо на GitHub Pages

Сајт се сам објављује на **https://rodrigomigl54-png.github.io/4-lava/** при сваком спајању (merge) у `main` (`.github/workflows/deploy.yml`: тестови → build → објава).

Једнократно подешавање: на GitHub-у отворите репозиторијум → **Settings → Pages → Build and deployment → Source: „GitHub Actions“**. Затим **Actions → „Deploy to GitHub Pages“ → Run workflow** (или само следећи merge).

- Адреса је јавна (свако са линком је може отворити), али је у демо режиму `noindex`, па се не појављује на Google-у.
- Кад стигне прави домен: у **Settings → Secrets and variables → Actions → Variables** додајте `PUBLIC_SITE_URL` = `https://www.pravi-domen.rs` (и `PUBLIC_DEMO` = `false` при објави).
- Под-путања `/4-lava/` се аутоматски узима из `PUBLIC_SITE_URL`; сви линкови, фонтови и слике је поштују.

## Објава (launch)

```bash
PUBLIC_DEMO=false PUBLIC_SITE_URL=https://www.pravi-domen.rs npm run build
```
`dist/` се поставља на Netlify / Vercel / GitHub Pages (статички сајт, без сервера). Са `PUBLIC_DEMO=false` нестаје `noindex`, `robots.txt` дозвољава индексирање и показује на `sitemap.xml` (све три језичке верзије са `hreflang`).

## Квалитет (мерено, мобилни профил Lighthouse-а)

| Страна | Performance | Accessibility | Best practices | SEO* |
|---|---|---|---|---|
| `/` | 91–96 (LCP 1,2 s) | 100 | 100 | 100 |
| `/meni/` | 100 (LCP 0,9 s) | 100 | 100 | 100 |

\* SEO 100 у режиму објаве (`PUBLIC_DEMO=false`); у демо режиму је намерно 66 због `noindex`.
- axe-core (WCAG 2.1 AA): 0 грешака на свих 6 страна, дневни и вечерњи режим.
- `prefers-reduced-motion`: без анимација, паралаксе и тока воде — одмах завршни кадар.
- JSON-LD: `Restaurant` (адреса, координате, радно време, оцена, `hasMenu`) на почетној; `Menu` → `MenuSection` → `MenuItem` са ценама на `/meni/`.
- Текстуре су унапред рендероване (зрно папира 11 KB PNG, мермер 18 KB WebP) уместо живих SVG филтера — уштеда ~0,5 s рендеровања на телефону.

## Логотип
`public/brand/logo-lion.jpg` (оригинал) је векторизован potrace-ом у `logo-lion.svg` (боја = `currentColor`, може златно на тамном / црно на крем) и `logo-lion-half.svg` (уско исечен). Свих пет лавова на сајту (лого + четири лава навигације) користе исти векторски траг — различити исечак, огледало и нагиб.

## Фонтови
Самостално хостовани (woff2, latin + latin-ext + cyrillic): Cormorant Garamond (наслови), Lora (текст), Caveat (рукопис, само табла и књига утисака). Cormorant и Lora имају српске облике (`locl` SRB) за курзивна б, г, д, п, т — проверено визуелно. Caveat нема српске алтернативе, па се користи само усправно.
